# Detection Engineering Method

1. Define threat behavior and ATT&CK mapping.
2. Identify authoritative telemetry and decoded fields.
3. Build the narrowest useful rule and validate XML.
4. Execute a harmless authorized test; preserve raw and alert evidence.
5. Investigate context, false positives, and rule interactions.
6. Tune specificity, severity, grouping, frequency, timeframe, and suppression.
7. Record status without equating configuration with detection success.

CDB lists scale classifications across executables. Frequency rules distinguish recurrence from isolated events. Stage rules normalize heterogeneous alerts into a common group for higher-level correlation.
